# Unitary collapse of Schrödinger's cat state
Physical Review A 110, L030202 (2024)
https://doi.org/10.1103/PhysRevA.110.L030202

### Source codes for generating data and figures

All data for the research paper <a href="https://doi.org/10.1103/PhysRevA.110.L030202">Unitary collapse of Schrödinger's cat state</a> have been computed using this code.

<ul>
    <li>
        Figure 2: <a href="https://github.com/PavelStransky/CollapsedCat/blob/cat/tasks/CollapsedCat/WignerHusimi.jl">WignerHusimi.jl</a>
    </li>
    <li>
        Figure 3: <a href="https://github.com/PavelStransky/CollapsedCat/blob/cat/tasks/CollapsedCat/X.jl">X.jl</a>
    </li>
    <li>
        Figure 4: <a href="https://github.com/PavelStransky/CollapsedCat/blob/cat/tasks/CollapsedCat/ParityViolationMaps.jl">ParityViolationMaps.jl</a>
    </li>
    <li>
        Figure 5: <a href="https://github.com/PavelStransky/CollapsedCat/blob/cat/tasks/CollapsedCat/Lindblad.jl">Lindblad.jl</a>, <a href="https://github.com/PavelStransky/CollapsedCat/blob/cat/tasks/CollapsedCat/LindbladScaling.jl">LindbladScaling.jl</a> (inset)
    </li>
</ul>

The remaining source files were used for additional numerical analyses and to investigate in detail the behaviour of the system under other parameter choices.
